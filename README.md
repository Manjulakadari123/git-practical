# Git & GitHub Practical Assignment

## Project Overview
This repository was created as part of a Git and GitHub practical assignment. It demonstrates the basic Git workflow, including repository creation, committing changes, branching, merging, and using GitHub.

## Objectives
- Install Git
- Configure Git username and email
- Create a GitHub repository
- Clone the repository
- Add and commit project files
- Push changes to GitHub
- Create and merge branches
- Create a README.md file
- Configure a .gitignore file

## Project Files
- `index.html` – Sample HTML page
- `README.md` – Project documentation
- `.gitignore` – Git ignore configuration

## Git Commands Used

```bash
git clone <repository-url>
git add .
git commit -m "Initial commit"
git push origin main
git checkout -b feature
git merge feature
```
